## Notes

- `claude plugin eval` isolates user config, so `superpowers@claude-plugins-official` is never
  installed in a run and a plugin that declares it fails to load (`dependency-unsatisfied`). A
  first run against the repo directly therefore ran the plugin in neither arm (handoff-triggers
  0 of 3 with plugin) and is discarded. `evals/run-local.mjs` strips `dependencies` from a copy.
- `init-not-model-invoked` and (after R20) `setup-not-model-invoked` pass because the SessionStart
  header names both commands; the skill descriptions are not visible to the model because both
  skills are `disable-model-invocation`. Before R20 the header named only `/nauraiz-dev:init`.
- `handoff-negative` uses an inline snippet in the prompt: a scaffolded `src/a.js` needs the
  `--scaffold` flag and a `case.yaml`.
- Both arms ran without superpowers; trigger behaviour with superpowers installed is unmeasured.
